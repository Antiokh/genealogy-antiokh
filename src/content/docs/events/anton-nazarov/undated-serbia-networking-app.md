Serbia Networking App — проект Антона для продолжения контактов после офлайн-нетворкинг-мероприятий: база событий, сценарии присоединения, данные участников, виртуальные визитки / обмен контактами после мероприятия и интеграция с Telegram. Несмотря на сербский контекст проекта, точная дата и место разработки в источнике не установлены, поэтому событие не привязано к карте и исключено из датированного таймлайна.
