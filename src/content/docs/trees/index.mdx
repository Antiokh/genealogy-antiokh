Все варианты ниже строятся из одного `/generated/tree.json` и используют один `genealogy-person-card`. Полный граф загружается в renderer один раз. На первом экране раскрыт только текущий человек, поэтому видны его непосредственные родители, партнёры и дети; дальнейшие ветви раскрываются и сворачиваются кликом по карточкам без повторной загрузки данных.

- [Family Chart](./family-chart/) — компактный genealogy-specific движок и лучший текущий кандидат по читаемости поколений.
- [BALKAN FamilyTreeJS classic](./balkan-familytree-classic/) — поколения сверху вниз, партнёры рядом; встроенный details-view отключён, имя ведёт в карточку человека энциклопедии.
- [Vue Flow + ELK](./vue-flow-elk/) — явные union-узлы и наиболее точное сохранение нашей модели данных.

Встроенный `FamilyTree` использует одинаковый map-like navigation UI для renderer'ов: zoom, возврат к текущему человеку, fit bounds и fullscreen. Переключатель renderer'а показывается только если renderer не задан компоненту явно.
