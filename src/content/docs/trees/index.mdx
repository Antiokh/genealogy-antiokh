Все варианты ниже строятся из одного generated-файла `genealogy-tree-1` и используют один `genealogy-person-card`.

- [Family Chart](./family-chart/) — компактный genealogy-specific движок и лучший текущий кандидат по читаемости поколений.
- [BALKAN FamilyTreeJS 2](./balkan-familytree2/) — genealogy-specific движок с нативными spouse/parent pair relations.
- [Vue Flow + ELK](./vue-flow-elk/) — явные union-узлы и наиболее точное сохранение нашей модели данных.
