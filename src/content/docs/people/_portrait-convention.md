A person's default portrait is an optional WebP file next to the person Markdown file with the same basename. For example, `1880-1889/vladimir-bush.md` uses `1880-1889/vladimir-bush.webp` when that file exists. This draft note is intentionally not published and exists only to keep the asset convention close to the people collection.
